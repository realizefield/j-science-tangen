⚡ 電気分解とは

電解質の水溶液（または融解した電解質）に電流を流し、物質を分解することを電気分解という。
電源の＋極につないだ電極を陽極（＋極）、−極につないだ電極を陰極（−極）という。

イオンと電極の関係：
陽イオン（＋）→ 陰極（−極） へ引き寄せられる
陰イオン（−）→ 陽極（＋極） へ引き寄せられる

🧪 塩酸（HCl）の電気分解

塩酸（HCl）を水に溶かすと次のように電離する。

HCl  →  水素イオン（H+）＋ 塩化物イオン（Cl−）

電流を流すと、それぞれのイオンが電極に引き寄せられて変化する。

陰極（−極）での変化：
H+（水素イオン）が電子を受け取り、水素（H₂）が発生する。
2H+ + 2e− → H₂
陽極（＋極）での変化：
Cl−（塩化物イオン）が電子を放出し、塩素（Cl₂）が発生する。
2Cl− → Cl₂ + 2e−
⚗️ 電極では何が起きているの？（原子レベルで見てみよう）
🔴 陰極（−極）のくわしいしくみ

① 溶液中のH+（水素イオン）は、−極の電極に引きつけられてやってきます。
② 電源の−極から電極に電子（e−）が流れ込んでいます。
③ H+はその電子を1個受け取り、電気を持たない水素原子（H）になります。
   H+ + e− → H
④ しかし水素原子（H）は単独では不安定です。そこで、隣にできた水素原子とすぐに結合し、水素分子（H₂）になります。
   H + H → H₂
⑤ この H₂ が気泡となって電極から出てきます。
🔵 陽極（＋極）のくわしいしくみ

① 溶液中のCl−（塩化物イオン）は、＋極の電極に引きつけられてやってきます。
② 電源の＋極は電子を引き抜く力を持っています。電極はCl−から電子を1個受け取ります。
③ 電子を1個失ったCl−は、電気を持たない塩素原子（Cl）になります。
   Cl− → Cl + e−
④ しかし塩素原子（Cl）も単独では不安定です。隣にできた塩素原子とすぐに結合し、塩素分子（Cl₂）になります。
   Cl + Cl → Cl₂
⑤ この Cl₂ が気泡となって電極から出てきます。黄緑色で刺激臭のある気体です。
※ まとめると：イオンが電子を「受け取る」か「渡す」かで、原子に戻り、原子同士が結合して分子（気体）になります。
全体の化学反応式：
2HCl → H₂ ＋ Cl₂
★ まとめ
  • 陰極（−極）で 水素（H₂）発生
  • 陽極（＋極）で 塩素（Cl₂）発生
  • 化学反応式：2HCl → H₂ + Cl₂

✏️ 塩酸の電気分解 確認問題（全7問）
問1塩酸の電気分解では、陰極（−極）から水素が発生する。
○ 正解です。H+（水素イオン）が陰極で電子を受け取り、水素（H₂）が発生します。
問2塩素は無色・無臭の気体である。
× 塩素は黄緑色で刺激臭のある有毒な気体です。
問3塩酸の電気分解の化学反応式は 2HCl → H₂ + Cl₂ である。
○ 正解です。2HCl → H₂ + Cl₂ が正しい化学反応式です。
問4塩酸の電気分解で、陽極（＋極）から発生する気体はどれか。
正解はイ：塩素（Cl₂）。Cl−（塩化物イオン）が陽極で電子を放出し、Cl₂が発生します。
問5塩素の性質として正しいものはどれか。
正解はウ。塩素は黄緑色・刺激臭・有毒で、漂白・殺菌作用があります。
問6塩酸の電気分解で、発生する気体の体積比（陰極：陽極）として正しいのはどれか。
正解はア：1 : 1。2HCl → H₂ + Cl₂ の反応式より、発生する水素と塩素は等しい物質量・等しい体積比（1：1）です。
問7塩酸の電気分解の化学反応式として正しいものはどれか。
正解はイ：2HCl → H₂ + Cl₂。係数に注意！左辺はHCl×2、右辺はH₂（分子）とCl₂（分子）。原子の数は H：2＝2、Cl：2＝2 で一致します。

🧪 塩化銅（CuCl₂）水溶液の電気分解

塩化銅（CuCl₂）を水に溶かすと青色の水溶液になり、次のように電離する。

CuCl₂  →  銅イオン（Cu2+）＋ 2塩化物イオン（2Cl−）
図：塩化銅の電気分解（ion8.png）
陰極（−極）での変化：
Cu2+（銅イオン）が電子を受け取り、赤褐色の銅（Cu）が析出する。
Cu2+ + 2e− → Cu
陽極（＋極）での変化：
Cl−（塩化物イオン）が電子を放出し、塩素（Cl₂）が発生する。
2Cl− → Cl₂ + 2e−
全体の化学反応式：
CuCl₂ → Cu ＋ Cl₂

水溶液の色の変化

電気分解が進むにつれて、Cu2+（銅イオン）が減っていくため、水溶液の青色が薄くなっていく。

★ まとめ
  • 陰極（−極）→ 赤褐色の銅（Cu）が析出
  • 陽極（＋極）→ 塩素（Cl₂）が発生
  • 反応式：CuCl₂ → Cu + Cl₂
  • 水溶液の青色はしだいに薄くなる

✏️ 塩化銅の電気分解 確認問題（全5問）
問1塩化銅水溶液の電気分解で、陰極（−極）に赤褐色の物質が付着する。
○ 正解です。Cu2+（銅イオン）が陰極で電子を受け取り、赤褐色の銅が析出します。
問2塩化銅水溶液の電気分解が進むと、水溶液の色は濃くなる。
× Cu2+（銅イオン）が減るため、青色は薄くなります。
問3塩化銅水溶液を電気分解すると陽極から塩素が発生する。
○ 正解です。Cl−が陽極で電子を放出し、塩素（Cl₂）が発生します。
問4塩化銅（CuCl₂）の電気分解で、陰極（−極）に析出する物質はどれか。
正解はウ：銅（Cu）。Cu2+が陰極で電子を受け取り、赤褐色の銅が析出します。
問5塩化銅（CuCl₂）の電気分解の化学反応式として正しいものはどれか。
正解はイ：CuCl₂ → Cu + Cl₂。銅と塩素が 1：1 の比で生成します。

🔋 化学電池とは

2種類の異なる金属と電解質水溶液を使って、化学エネルギーを電気エネルギーに変換する装置を化学電池という。

重要： 非電解質（砂糖水など）ではイオンが生じないため、電池を作ることができない。

⚡ 亜鉛板・銅板を希硫酸に入れた場合

図：化学電池の実験（ion9.png）
亜鉛板（−極）での変化：
亜鉛（Zn）がとけてイオンになり、電子を放出する。
Zn → Zn2+ + 2e−
※ イオン化傾向が大きい方の金属が −極 になる
銅板（＋極）での変化：
H+（水素イオン）が電子を受け取り、水素（H₂）が発生する。
2H+ + 2e− → H₂

  • 化学電池：化学エネルギー → 電気エネルギー

  • イオン化傾向が小さい方 → ＋極（水素発生）
  • 電解質水溶液でないと電池にならない

🌿 燃料電池

水素と酸素を反応させて電気エネルギーを取り出す電池を燃料電池という。

2H₂ ＋ O₂ → 2水（2H₂O）
（この反応で電気エネルギーと熱エネルギーが生じる）
特徴 内容
燃料 水素（H₂）
排出されるもの 水（H₂O）のみ（CO₂を出さない）
発電効率 高い（熱損失が少ない）
用途 燃料電池自動車（FCV）・家庭用発電（エネファーム）
★ 電気分解 vs 化学電池 まとめ
  • 電気分解：電気エネルギー → 化学変化（物質を分解）
  • 化学電池：化学エネルギー → 電気エネルギー
  • 燃料電池：水素＋酸素 → 水 ＋ 電気エネルギー

✏️ 化学電池・燃料電池 確認問題（全6問）
問1化学電池では、イオン化傾向が大きい金属が−極になる。
○ 正解です。イオンになりやすい（イオン化傾向が大きい）金属が−極になり、溶けていきます。
問2砂糖水に亜鉛板と銅板を入れると化学電池になる。
× 砂糖水は非電解質なのでイオンが生じません。電解質水溶液でないと電池は作れません。
問3燃料電池は水素と酸素から電気を取り出し、水のみを排出する。
○ 正解です。2H₂ + O₂ → 2H₂O の反応から電気を取り出します。CO₂を排出しないのが特徴です。
問4亜鉛板と銅板を希硫酸に入れた化学電池で、−極になるのはどちらか。
正解はイ：亜鉛板（Zn）。ZnはCuよりイオン化傾向が大きいため、Znが溶けて電子を放出し−極になります。
問5次のうち、化学電池に使える組み合わせはどれか。
正解はウ。化学電池の条件は「異なる2種類の金属＋電解質水溶液」です。砂糖水は非電解質なのでNG、同じ金属2枚もNG。
問6イオン化傾向の大きい順として正しいものはどれか。
正解はア：Mg ＞ Al ＞ Zn ＞ Fe ＞ Cu。この順番はよく試験に出ます。Mgが最もイオンになりやすく、Cuが最もなりにくいです。
