問1酸の水溶液にリトマス試験紙（青色）をつけると赤色に変化する。
○ 正解です。酸の水溶液はH⁺を含み、青色リトマスを赤色に変えます。
問2アルカリの水溶液には水素イオン（H⁺）が多く含まれている。
× アルカリの水溶液には水酸化物イオン（OH⁻）が多く含まれています。H⁺が多いのは酸性です。
問3BTB溶液が緑色を示す水溶液はどれか。
正解はイ：中性の水溶液。BTBは酸性=黄・中性=緑・アルカリ性=青と覚えましょう。
問4フェノールフタレイン溶液を加えると赤（桃）色になる水溶液はどれか。
正解はウ：アルカリ性。フェノールフタレインはアルカリ性のときだけ赤（桃）色になります。酸性・中性では無色です。
2中和と塩（えん）
🔑 キーワード
中和……酸性の水溶液とアルカリ性の水溶液を混ぜると、それぞれの性質を互いに打ち消し合う反応
塩（えん）……中和によってできた物質（NaCl・BaSO₄など）
💡 中和の本質
酸のH⁺とアルカリのOH⁻が結合して水（H₂O）ができます。
H⁺ ＋ OH⁻ → H₂O
この反応が中和の核心です。

📝 ミニテスト　塩酸と水酸化ナトリウム水溶液の中和
問1塩酸（HCl）の電離式として正しいものはどれか。
正解はア：HCl → H⁺ ＋ Cl⁻。塩酸は水中で水素イオン（H⁺）と塩化物イオン（Cl⁻）に電離します。イは電荷がなく誤り。ウ・エはイオンの価数が誤りです。
問2水酸化ナトリウム（NaOH）の電離式として正しいものはどれか。
正解はイ：NaOH → Na⁺ ＋ OH⁻。NaOHは水中でナトリウムイオン（Na⁺）と水酸化物イオン（OH⁻）に電離します。このOH⁻がアルカリ性の原因です。
問3塩酸と水酸化ナトリウム水溶液の中和の化学反応式として正しいものはどれか。
正解はウ：HCl ＋ NaOH → NaCl ＋ H₂O。係数を確認すると両辺ともNa1・Cl1・H2・O1で一致します。アはH₂Oが正しく書かれておらず、イ・エは係数が合いません。
問4問3の反応でできた塩（えん）の名称として正しいものはどれか。
正解はエ：塩化ナトリウム（NaCl）。HClのCl⁻とNaOHのNa⁺が結びついてできた塩（えん）が塩化ナトリウムです。食塩（NaCl）と同じ物質です。
問5問4の塩（えん）である塩化ナトリウム（NaCl）の性質として正しいものはどれか。
正解はア。塩化ナトリウム（NaCl）は水によく溶ける塩（えん）で、水溶液は中性を示します。水に溶けにくい沈殿になるのは硫酸バリウム（BaSO₄）などです。
問6水素イオン（H⁺）と水酸化物イオン（OH⁻）の中和反応式として正しいものはどれか。
正解はイ：H⁺ ＋ OH⁻ → H₂O。中和の本質はこの式です。H⁺とOH⁻が1：1の比で結合して水（H₂O）ができます。アのH₂O₂は過酸化水素で別物です。
問7塩酸と水酸化ナトリウム水溶液を中和したのち、水溶液を加熱・自然乾燥すると白色の粉末が見られた。この物質は何か。
正解はエ：塩化ナトリウム（NaCl）。HCl ＋ NaOH → NaCl ＋ H₂O の反応でできた塩化ナトリウムは、水を蒸発させると白色の結晶（食塩）として残ります。
📝 ミニテスト　硫酸と水酸化バリウムの中和
問1硫酸（H₂SO₄）の電離式として正しいものはどれか。
正解はア：H₂SO₄ → 2H⁺ ＋ SO₄²⁻。硫酸は2価の酸で、水中でH⁺を2個放出します。SO₄²⁻は硫酸イオン（価数2−）です。イはH⁺の係数が抜けており、エはSO₄の価数が誤りです。
問2水酸化バリウム（Ba(OH)₂）の電離式として正しいものはどれか。
正解はイ：Ba(OH)₂ → Ba²⁺ ＋ 2OH⁻。バリウムは2価の陽イオン（Ba²⁺）になり、OH⁻を2個放出します。アは電荷がなく誤り。ウはBaの価数が間違いです。
問3硫酸と水酸化バリウム水溶液の中和の化学反応式として正しいものはどれか。
正解はウ：H₂SO₄ ＋ Ba(OH)₂ → BaSO₄ ＋ 2H₂O。両辺を確認すると Ba1・S1・O6・H4で一致します。H₂SO₄のH₂とBa(OH)₂の(OH)₂が2個の水（2H₂O）をつくる点がポイントです。
問4問3の反応でできた塩（えん）はどれか。
正解はエ：硫酸バリウム（BaSO₄）。H₂SO₄のSO₄²⁻とBa(OH)₂のBa²⁺が結びついてできた塩（えん）が硫酸バリウムです。
問5問4の硫酸バリウム（BaSO₄）は水に溶けるか。
正解はイ：溶けない。BaSO₄は水にほとんど溶けない白色の固体で、中和反応によって白色の沈殿として生じます。これが塩酸とNaOHの中和（NaClは水に溶ける）との大きな違いです。

🎓 各点の解説 — ビーカーの中のイオンはどうなっているの？
a 点 a （実験開始直後）→ 図イ
　ビーカーの中にはまだ水酸化ナトリウム水溶液を加えていません。 塩酸（HCl）だけが入っているので、水溶液中には H⁺（水素イオン） と Cl⁻（塩化物イオン） がたくさん存在しています。 イオンが多いので電流も大きくなります。図イのビーカーにH⁺とCl⁻がびっしり並んでいるのがその証拠です！
b 点 b （中和途中）→ 図エ
　NaOH水溶液を少し加えた状態です。加えた NaOH の OH⁻ が H⁺ と結合して水（H₂O）になり、 H⁺ の数が減り始めています。ただし H⁺ はまだ残っています。 図エのように、H₂O・Na⁺・Cl⁻・H⁺ が混在している状態です。 イオン全体の数が減ってきているので電流も少し下がります。
c 点 c （中和点＝電流が最小）→ 図ウ
　H⁺ がすべて OH⁻ と結合して水になり、H⁺ がゼロになった瞬間が中和点です。 ビーカーの中には Na⁺ と Cl⁻ だけが残り、どちらも中和反応とは無関係に水溶液中に留まります。 図ウのように Na⁺・Cl⁻・H₂O だけになります。 H⁺ と OH⁻ が消えてもイオンはゼロにならない（Na⁺ と Cl⁻ が残る）ため、電流もゼロにはなりません。
d 点 d （中和点を過ぎた後）→ 図ア
　NaOH を加えすぎた状態です。H⁺ はゼロになっているので、 加えた NaOH の Na⁺ と OH⁻ がそのまま水溶液中に増えていきます。 図アのように Na⁺・OH⁻・Cl⁻・H₂O が混在していて、イオンの数が増えるほど電流が大きくなります。 グラフで点 d 以降の電流が右肩上がりになっているのはこのためです！

📋 問題
次の図は、塩酸に水酸化ナトリウム水溶液を加えていく中で、 あるイオンの数の変化をあらわしたものです。 ア〜エのグラフは、それぞれどのイオンの変化を表しているでしょうか。
図：イオンの数の変化（ion15.png）
🔬 各グラフのイオンは何？ 詳しく見てみよう！
ア H⁺（水素イオン）のグラフ
　塩酸を最初にビーカーに入れたとき、H⁺ はたくさんいます。 NaOH 水溶液を加えるたびに H⁺ ＋ OH⁻ → H₂O の反応が起き、H⁺ がどんどん減ります。 中和点（NaOH がちょうど同量になった点）で H⁺ はゼロになり、 そのあとはいくら NaOH を加えても H⁺ は増えません（ゼロのまま）。 → グラフは 右下がりでゼロになり、そのあと水平（ア） になります！
イ Na⁺（ナトリウムイオン）のグラフ
　Na⁺ は NaOH 水溶液と一緒に加えられます。実験の最初はゼロですが、 NaOH を加えるたびに Na⁺ が増えていきます。 中和反応が起きても Na⁺ は消費されません（H⁺ と結合しないのです）。 だから加えれば加えるほどずっと増え続けます。 → グラフは ゼロから右肩上がり（イ） になります！
ウ OH⁻（水酸化物イオン）のグラフ
　OH⁻ は NaOH 水溶液と一緒に加えられますが、加えた端から H⁺ と結合して水になります。 だから中和点までは OH⁻ はゼロのままです。 中和点を過ぎると H⁺ がなくなるので、余った OH⁻ がそのまま水溶液中に残るようになります。 → グラフは 中和点まで水平（ゼロ）で、その後右肩上がり（ウ） になります！
エ Cl⁻（塩化物イオン）のグラフ
　Cl⁻ は最初から塩酸（HCl）の中に入っていて、中和反応が起きても消費されません。 HCl → H⁺ ＋ Cl⁻ と電離したClはずっとそのまま水溶液中にあり続けます。 NaOH を加えても加えなくても Cl⁻ の数は変わりません。 → グラフは ずっと水平（エ） になります！
🌟 まとめの覚え方：
　ア（H⁺）= 右下がりでゼロに
　イ（Na⁺）= ゼロから右上がり
　ウ（OH⁻）= 中和点まで水平、あとで上がる
　エ（Cl⁻）= ずっと水平（変化なし）
⚡ なぜ電流が変化するの？
中和点まで（電流が減少）：
　NaOH水溶液を加えるたびに H⁺ が OH⁻ と結合して水（H₂O）になるため、 イオンの数が減り電流が下がります。

中和点（電流が最小）：
　H⁺ がすべて消費されます。ただし Na⁺ と Cl⁻ は残るので電流はゼロにはなりません。

中和点を超えたあと（電流が増加）：
　余分な Na⁺ と OH⁻ が加わりイオンの数が増えるため電流が増えます。

📝 確認問題
問10BTB溶液が緑色のとき、水溶液は中性（中和点）である。
○ 正解です。BTBの緑色は中性のサインです。塩酸にNaOH水溶液を加えてBTBが緑になった点が中和点（完全中和）です。
問11HCl + NaOH の中和点では、溶液中のすべてのイオンがゼロになる。
× 中和点でもNa⁺とCl⁻は溶液中に残ります。ゼロになるのはH⁺とOH⁻だけです。そのため電流はゼロにならず、最小値になります。
問12塩酸20cm³をNaOH水溶液30cm³で完全に中和した。塩酸30cm³を完全に中和するには何cm³のNaOH水溶液が必要か。
正解はウ：45cm³。比例計算：20：30 ＝ 30：χ　→　20χ ＝ 30×30　→　χ ＝ 45（cm³）
問13塩酸にNaOH水溶液を加えていくとき、電流の変化として正しいものはどれか。
正解はエ。中和点でNa⁺・Cl⁻が残るため電流はゼロにならず最小値をとります。中和点を過ぎると余分なNa⁺・OH⁻が増えて電流は増加します。
問14塩酸＋NaOH水溶液の中和実験で中和点を超えてNaOHを加えすぎた後、水分を蒸発させると残る固体は何か。
正解はイ。中和点を超えているので余分なNaOHが溶液中に残っています。蒸発させるとNaCl（中和で生じた塩）とNaOH（余分なアルカリ）の両方が固体として残ります。

🎓 各点の解説 ── 塩酸のときと何がちがうの？
a 点 a（実験開始直後）→ 図イ
　ビーカーには硫酸（H₂SO₄）だけが入っています。 H₂SO₄ → 2H⁺ ＋ SO₄²⁻ と電離しているので、 H⁺ と SO₄²⁻ がたくさん存在しています。 イオンが多いので電流が大きくなります（図イ）。
b 点 b（中和途中）→ 図ウ
　Ba(OH)₂ 水溶液を少し加えた状態です。 OH⁻ が H⁺ と結合して水に、Ba²⁺ が SO₄²⁻ と結合して 硫酸バリウム（BaSO₄）の白色沈殿になります。 H⁺ も SO₄²⁻ もどちらも減っているため電流が下がります（図ウ）。
c 点 c（中和点＝電流がゼロ！）→ 図エ
　塩酸のときとの大きな違いがここです！ H₂SO₄ ＋ Ba(OH)₂ → BaSO₄↓ ＋ 2H₂O の反応で、 H⁺・SO₄²⁻・Ba²⁺・OH⁻ のすべてのイオンが消費されます。 BaSO₄ は水に溶けないので沈殿し、水溶液中にイオンが残りません。 そのため電流は本当にゼロ（0 mA）になります（図エ）。 塩酸のときは Na⁺ と Cl⁻ が残ったのでゼロにならなかった点と比べてみましょう！
d 点 d（中和点を過ぎた後）→ 図ア
　Ba(OH)₂ を加えすぎた状態です。 もう H⁺ も SO₄²⁻ もゼロなので、余分な Ba²⁺ と OH⁻ が水溶液に溶け込んでいきます。 BaSO₄ の沈殿は底に残ったままですが、Ba²⁺ と OH⁻ のおかげでイオンが増え電流が再び上がります（図ア）。
⚡ H₂SO₄ ＋ Ba(OH)₂ 電流変化のまとめ
中和点まで（電流が減少）：
　Ba(OH)₂ を加えるたびに、H⁺ ＋ OH⁻ → H₂O　かつ　Ba²⁺ ＋ SO₄²⁻ → BaSO₄↓ の2つの反応が同時に起き、イオンが急速に減ります。

中和点（電流がゼロ）：
　4種類のイオン（H⁺・SO₄²⁻・Ba²⁺・OH⁻）がすべて消費され、水溶液中のイオンがゼロになります。電流も 0 mA になります！

中和点を超えたあと（電流が増加）：
　余分な Ba²⁺ と OH⁻ が増えるため電流が増えます。
📈 イオンの数の変化グラフ（H₂SO₄ + Ba(OH)₂）
📋 問題
次の図は、硫酸に水酸化バリウム水溶液を加えていく中で、 あるイオンの数の変化をあらわしたものです。 ア〜オのグラフは、それぞれどのイオンの変化を表しているでしょうか。 ただし、ア〜オのうち1つはどのイオンにも当てはまりません（ダミー）。
図：イオンの数の変化（ion17.png）
🔬 各グラフのイオンは何？ 詳しく解説！
ア H⁺（水素イオン）のグラフ
　硫酸は H₂SO₄ → 2H⁺ ＋ SO₄²⁻ と電離するので、最初は H⁺ がたくさんいます。 Ba(OH)₂ を加えるたびに H⁺ ＋ OH⁻ → H₂O の反応が起き、H⁺ が減っていきます。 中和点で H⁺ はゼロになり、そのまま増えません。 → グラフは 最初から右下がりでゼロになり、その後水平（ア）。
イ ダミーのグラフ（当てはまるイオンなし）
　「ゼロから右肩上がりで一直線」のグラフは、H₂SO₄ ＋ Ba(OH)₂ の系では存在しません。 HCl ＋ NaOH のときの Na⁺（加え始めからずっと増える）に似た形ですが、 Ba²⁺ はすぐ BaSO₄ になるのでこの形にはなりません。 → どのイオンにも当てはまらないダミーです！引っかからないように注意しましょう。
ウ OH⁻（水酸化物イオン）のグラフ
　OH⁻ は Ba(OH)₂ と一緒に加えられますが、加えた端から H⁺ と結合して水になります。 中和点まで OH⁻ はゼロのままです。 中和点を過ぎると H⁺ がなくなるので、余った OH⁻ が水溶液中に残り始めます。 → グラフは 中和点まで水平（ゼロ）、その後右肩上がり（ウ）。
エ SO₄²⁻（硫酸イオン）のグラフ
　硫酸から生じた SO₄²⁻ は最初から存在しますが（H⁺ の半分の量）、 Ba²⁺ が加わると Ba²⁺ ＋ SO₄²⁻ → BaSO₄↓ の反応ですぐに沈殿します。 中和点で SO₄²⁻ もゼロになり、その後は増えません（BaSO₄ が不溶なので）。 → グラフは アより低い位置から右下がりでゼロになり水平（エ）。 ※アの H⁺ より傾きが緩やか（最初の量がアの半分）な点がポイントです！
オ Ba²⁺（バリウムイオン）のグラフ
　Ba²⁺ は Ba(OH)₂ と一緒に加えられますが、加えた端から SO₄²⁻ と結合して BaSO₄ として沈殿します。 だから中和点まで Ba²⁺ は水溶液中にほとんどゼロのままです。 中和点を過ぎると SO₄²⁻ がなくなるので、余った Ba²⁺ が水溶液中に残り始めます。 → グラフは 中和点まで水平（ゼロ）、その後右肩上がり（オ）。 ウ（OH⁻）と形は同じですが、Ba²⁺ は OH⁻ の半分の量しかない点が異なります。
🌟 H₂SO₄ ＋ Ba(OH)₂ まとめ表

　ア（H⁺）　 = 最初から減少 → ゼロで水平
　イ　　　　 = ダミー（当てはまらない）
　ウ（OH⁻）　= 中和点まで水平 → その後上昇
　エ（SO₄²⁻）= 最初から減少（傾きはアより緩やか）→ ゼロで水平
　オ（Ba²⁺）　= 中和点まで水平 → その後上昇（ウより量は少ない）

🔑 塩酸との最大の違い：HCl ＋ NaOH は中和点でイオンが残るが、 H₂SO₄ ＋ Ba(OH)₂ は中和点でイオンがゼロになり電流も 0 mA！
📝 確認問題　イオンの数の変化グラフ（H₂SO₄ + Ba(OH)₂）
ion17.png のグラフ ア〜オ を参考に答えてください。
問1硫酸（H₂SO₄）と水酸化バリウム（Ba(OH)₂）水溶液の中和実験で、H⁺（水素イオン）の数の変化を表すグラフはどれか。
正解はア。H⁺ は最初（硫酸のみ）のとき最も多く、Ba(OH)₂ を加えるたびに H⁺ ＋ OH⁻ → H₂O の反応でどんどん減ります。中和点でゼロになり、その後も増えません。最初の量が一番多いのでグラフの傾きも急です。
問2Ba²⁺（バリウムイオン）の数の変化を表すグラフはどれか。
正解はオ。Ba²⁺ は Ba(OH)₂ と一緒に加えられますが、すぐに Ba²⁺ ＋ SO₄²⁻ → BaSO₄↓ の反応で沈殿してしまいます。中和点まで Ba²⁺ は水溶液中にほぼゼロ。中和点を過ぎると SO₄²⁻ がなくなるので余った Ba²⁺ が水溶液に残り始め、右肩上がりになります。OH⁻（ウ）と形は同じですが量が少ない点が異なります。
問3SO₄²⁻（硫酸イオン）の数の変化を表すグラフはどれか。
正解はエ。SO₄²⁻ は最初から存在しますが、Ba²⁺ が加わるたびに BaSO₄ として沈殿します。中和点でゼロになり、その後も増えません。H⁺（ア）と同じ形ですが、H₂SO₄ 1分子から H⁺ は2個・SO₄²⁻ は1個できるため、最初の量が H⁺ の半分で傾きが緩やかな点がポイントです。
問4OH⁻（水酸化物イオン）の数の変化を表すグラフはどれか。
正解はウ。OH⁻ は Ba(OH)₂ と一緒に加えられますが、加えた端から H⁺ ＋ OH⁻ → H₂O の反応で消費されます。中和点までは OH⁻ がゼロのまま。中和点を過ぎると H⁺ がなくなるため、余った OH⁻ が水溶液中に残り始めて増えていきます。
問5硫酸と水酸化バリウムの中和実験では、中和点で電流が 0 mA になります。その理由として正しいものはどれか。
正解はイ。H₂SO₄ ＋ Ba(OH)₂ → BaSO₄↓ ＋ 2H₂O の反応では、生じた BaSO₄ が水にほとんど溶けないため沈殿します。これによって H⁺・SO₄²⁻・Ba²⁺・OH⁻ の4種類のイオンがすべて水溶液中から取り除かれます。その結果、電流を運ぶイオンがゼロになり電流が 0 mA になります。塩酸＋NaOH の中和では Na⁺ と Cl⁻ が残るためゼロにならない点と大きく異なります。
