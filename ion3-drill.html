A酸・アルカリの性質と指示薬
問1酸性の水溶液はすべて共通して、水素イオン（H⁺）を含んでいる。
○ 正解です。塩酸・酢酸・硫酸など、「酸」と名のつく物質はすべて水中でH⁺を生じます。このH⁺こそが酸性を示す共通の原因です。
問2フェノールフタレイン溶液はアルカリ性のとき黄色に変わる。
× アルカリ性で変わる色は赤（赤紫）です。酸性・中性では無色のままです。黄色に変わるのはBTB溶液（酸性のとき）です。
問3次のうち、アルカリ性の水溶液はどれか。
正解はウ：石灰水。水酸化カルシウム Ca(OH)₂ は水に溶けてOH⁻を生じるアルカリ性の水溶液です。ア・イ・エはいずれも酸性です。
問4酸性水溶液に共通して見られる性質として正しいものはどれか。
正解はエ。酸性水溶液（H⁺を含む）はマグネシウムなどの金属と反応して水素（H₂）を発生します。ア〜ウはいずれもアルカリ性の性質です。
B中和と塩（えん）
問5中和反応では、必ず酸とアルカリの両方が完全になくなる。
× 中和は「酸とアルカリが互いに打ち消し合う」反応ですが、量が異なれば一方が余ります。たとえば酸が多ければ、中和後も酸が残り、水溶液は酸性になります。
問6塩酸と水酸化ナトリウムを中和すると生じる塩化ナトリウム（NaCl）は、水に溶けてイオンに分かれるため電流を通す。
○ 正解です。NaCl は水中で Na⁺ と Cl⁻ に電離するため、電流をよく通します。このように水に溶けてイオンになる物質を電解質といいます。
問7硫酸（H₂SO₄）と水酸化ナトリウム（NaOH）の中和反応の化学反応式として正しいものはどれか。
正解はイ：H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O。H₂SO₄のH⁺は2個あるため、NaOHが2分子必要です。両辺の原子数を確認：Na2、S1、O6、H4 ✓
問8次の組み合わせで「塩化カルシウム（CaCl₂）」が生成するのはどれか。
正解はア。2HCl + Ca(OH)₂ → CaCl₂ + 2H₂O。酸の陰イオン（Cl⁻）とアルカリの陽イオン（Ca²⁺）が結びついて塩（えん）ができます。
C中和の計算
問9塩酸30cm³をちょうど中和するのに水酸化ナトリウム水溶液45cm³が必要であった。この塩酸10cm³を中和するには、同じ水酸化ナトリウム水溶液が15cm³必要である。
○ 正解です。中和に必要な体積は比例します。30 : 45 = 10 : 15（比率は常に2 : 3）。塩酸の体積が1/3になれば、必要なNaOHも1/3になります。
問10塩酸20cm³をちょうど中和するのに水酸化ナトリウム水溶液25cm³が必要である。この塩酸40cm³を中和するには、水酸化ナトリウム水溶液が何cm³必要か。
正解はウ：50cm³。比例式：20 : 25 = 40 : x → x = 25 × 40 ÷ 20 = 50cm³。塩酸が2倍になるので、NaOHも2倍の50cm³が必要です。
問11塩酸15cm³と水酸化ナトリウム水溶液20cm³がちょうど中和する。同じ塩酸45cm³を中和するには、水酸化ナトリウム水溶液が何cm³必要か。
正解はエ：60cm³。比例式：15 : 20 = 45 : x → x = 20 × 45 ÷ 15 = 60cm³。塩酸が3倍（15→45）になるので、NaOHも3倍（20→60）になります。
Dイオンと電離
問12砂糖（ショ糖）の水溶液は、電流をよく通す。
× 砂糖は非電解質で、水に溶けてもイオンにならないため電流を通しません。電流を通すのは NaCl や HCl などの電解質の水溶液です。
問13塩酸（HCl）が水に溶けたときの電離の式として正しいものはどれか。
正解はイ：HCl → H⁺ + Cl⁻。電離とは原子や分子が陽イオンと陰イオンに分かれることです。アは電荷を書いていないので誤り。ウ・エは存在しないイオンです。
問14水酸化ナトリウム（NaOH）の電離の式として正しいものはどれか。
正解はエ：NaOH → Na⁺ + OH⁻。NaOH は水中で Na⁺（ナトリウムイオン）と OH⁻（水酸化物イオン）に電離します。このOH⁻がアルカリ性の原因です。アはNaに電荷がなく誤り。イのOH₂⁻は存在しないイオン。ウのNa²⁺も存在しません。
E電流の変化（塩酸＋水酸化ナトリウム）
問15塩酸に水酸化ナトリウムを少量ずつ加えていくと、中和点では水溶液中の電流が 0（ゼロ）になる。
× 中和点では H⁺ と OH⁻ が反応して水（H₂O）になりますが、食塩（NaCl）が生成します。NaCl は水に溶けて Na⁺ と Cl⁻ にイオン化するため、電流は最小になりますが「0」にはなりません。HCl＋NaOH の中和では、生成する塩が水に溶けるので、中和点でもイオンが残ります。
問16塩酸に水酸化ナトリウムを加えていくとき、電流の大きさが変化する主な理由はどれか。
正解はイ。電流の大きさはイオンの数（＝電荷を持つ粒子の数）に比例します。H⁺ と OH⁻ が反応して水になるとイオン数が減り電流が小さくなり、中和点を過ぎると Na⁺ と OH⁻ が増えるため電流も増えます。
問17塩酸と水酸化ナトリウムの中和実験で、電流が最小（でも0ではない）になる理由として正しいものはどれか。
正解はウ。中和点では H⁺ と OH⁻ が反応して水になりますが、NaCl（食塩）が生じます。NaCl は Na⁺ と Cl⁻ に電離して残るので、イオンが完全になくなるわけではありません。だから電流は「最小」にはなっても「0」にはなりません。
問18HCl＋NaOH の実験で、NaOH を過剰に加えたあと、水溶液中で増えていくイオンの組み合わせはどれか。
正解はア：Na⁺ と OH⁻。中和点を過ぎると NaOH が余り始めます。NaOH は水中で Na⁺ と OH⁻ に電離するため、これらのイオン数が増え、電流が大きくなります。中和点では H⁺ はすべて水になっているので、「イ」はありえません。
F電流の変化（硫酸＋水酸化バリウム）
問19硫酸（H₂SO₄）に水酸化バリウム（Ba(OH)₂）を少量ずつ加えていくと、中和点では電流が 0（ゼロ）になる。
○ 正解です！硫酸バリウム（BaSO₄）は水にほとんど溶けない「難溶性の塩」です。H⁺ は OH⁻ と反応して水になり、SO₄²⁻ は Ba²⁺ と反応して BaSO₄ として沈殿します。中和点ではすべてのイオンがなくなり、電流は 0mA になります。これが HCl＋NaOH との大きな違いです！
問20H₂SO₄＋Ba(OH)₂ の反応で、中和点で電流が 0 になる理由として正しいものはどれか。
正解はウ。BaSO₄ は難溶性の塩で水にほとんど溶けません。H⁺ と OH⁻ が反応して水になり、SO₄²⁻ と Ba²⁺ が BaSO₄↓ として沈殿するため、中和点ではイオンが水溶液中から完全になくなり、電流が 0 になります。
問21硫酸と水酸化バリウムの中和反応の化学反応式として正しいものはどれか。
正解はエ。H₂SO₄ の H⁺ が2個、Ba(OH)₂ の OH⁻ が2個なので1対1の比で反応します。生成する BaSO₄ は水に溶けないため↓（沈殿）の記号をつけます。係数を確認：左辺 H₂SO₄1＋Ba(OH)₂1 → 右辺 BaSO₄↓1＋H₂O2 ✓
問22硫酸と水酸化バリウムの中和実験で、中和点を過ぎて水酸化バリウムを過剰に加えたあと、水溶液中で増えていくイオンはどれか。
正解はイ：Ba²⁺ と OH⁻。中和点を過ぎると Ba(OH)₂ が余ります。Ba(OH)₂ は水中で Ba²⁺ と 2OH⁻ に電離するため、これらのイオン数が増え、電流が再び大きくなります。H⁺ と SO₄²⁻ は中和点ですでになくなっています。
Gイオン数変化グラフ
問23HCl＋NaOH の中和実験で、NaOH を加えていく間、中和点まで「数がほぼ変化しない（一定）」イオンはどれか。
正解はア：Cl⁻。HCl が電離して生じた Cl⁻ は、NaOH を加えても反応せず水溶液中にそのまま残ります。H⁺ は OH⁻ と反応して減り、Na⁺ は NaOH から供給されて増え、OH⁻ は H⁺ と反応してなくなります（中和点以降に現れます）。
問24HCl＋NaOH の中和実験で、NaOH を加え始めたときから、加えた量に比例して「増加し続ける」イオンはどれか。
正解はオ：Na⁺。NaOH を加えると Na⁺ が供給され続けるため、加えた量に比例して Na⁺ の数が増えます。H⁺ は減少、Cl⁻ は一定、OH⁻ は中和点以降から増加します。SO₄²⁻ は HCl＋NaOH の実験には存在しないイオンです。
問25H₂SO₄＋Ba(OH)₂ の中和実験で、中和点に向けて数が減少し、中和点でちょうど 0 になるイオンの組み合わせはどれか。
正解はイ：H⁺ と SO₄²⁻。硫酸が電離した H⁺ は OH⁻ と反応して水になり、SO₄²⁻ は Ba²⁺ と反応して BaSO₄↓ として沈殿します。どちらも中和点でちょうどゼロになります。OH⁻ は Ba(OH)₂ を加えるにつれて供給されますが、H⁺ と反応してすぐ消えるため中和点まで「0」のままです。
問26中和実験のイオン数グラフについて、正しいものはどれか。
正解はエ。H₂SO₄＋Ba(OH)₂ の中和点では、H⁺ は OH⁻ と反応して水になり、SO₄²⁻ は Ba²⁺ と反応して BaSO₄↓ として沈殿します。すべてのイオンがなくなるため電流は 0mA になります。アは誤り（中和点で電流は最小になる）。イは誤り（中和点を過ぎると Ba²⁺ と OH⁻ が増えて電流も増加する）。ウは誤り（H⁺ は中和点に向けて減少する）。
問27H₂SO₄＋Ba(OH)₂ の実験で、Ba(OH)₂ を加え始めたとき「0」で、中和点を過ぎてから増加し始めるイオンの組み合わせとして正しいものはどれか。
正解はア：Ba²⁺ と OH⁻。Ba(OH)₂ が加わっても、中和点まで Ba²⁺ は SO₄²⁻ と反応して BaSO₄↓ として沈殿し、OH⁻ は H⁺ と反応して水になります。つまり中和点まではどちらも 0。中和点を過ぎて Ba(OH)₂ が余り始めると、初めて Ba²⁺ と OH⁻ が水溶液中に現れ、電流が増加します。
